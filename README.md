# Атлант / Watch

Закрытая рабочая версия системы мониторинга открытых сообщений об угрозах БПЛА вокруг Атлант‑Парка (Обухово).

## Что делает система

- проверяет 20 официальных и мониторинговых источников;
- отделяет официальные сообщения от неподтверждённых;
- фильтрует сообщения по территории и радиусам 5, 10, 20 и 30 км;
- отображает события на карте без координат целей;
- отправляет новые события в личный Telegram-чат без повторов;
- хранит историю отправок в Cloudflare D1.

Система использует публичные сообщения и не заменяет официальные оповещения МЧС и органов власти.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Для Telegram создайте локальный файл `.env.local`:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
```

Файлы `.env*` исключены из Git. Не добавляйте токен, ID чата или пароли в исходный код.

## Проверка

```bash
npm run lint
npm test
```

## Размещение

Проект рассчитан на Cloudflare Worker-совместимое окружение и использует привязку D1 с именем `DB`. Для опубликованной версии токен Telegram должен храниться в защищённых переменных окружения.

Важно: текущая отправка Telegram запускается запросами интерфейса. Для полностью автономной круглосуточной проверки нужен отдельный планировщик, вызывающий `/api/telegram/dispatch` с заданным интервалом.
